# Maintainers

The project is stewarded by the solidSF open-source maintainers.

Maintainers are responsible for:

- preserving the narrow host-memory RoCE claim boundary;
- requiring reproducible fixtures and tests for behavior changes;
- reviewing security, privacy, licensing, and vendor-attribution concerns;
- keeping historical evidence immutable or issuing explicit corrections;
- approving versions, tags, artifacts, and release notes; and
- separating this public utility from private solidSF platform code.

General changes should use the public repository's pull-request workflow.
Security and conduct reports go privately to `security@solidsf.com` as
described in [SECURITY.md](SECURITY.md).

Maintainer membership and release authority must be changed through a reviewed
repository update. No individual is granted release authority by this file
alone.
